## The exact recipe to run it (when disk + go-ahead are available)

Leave the unrelated `za-corruption-neo4j-1` container **untouched**; bring up isolated stores on
non-conflicting ports (mirror the `m7smoke` project from `docs/m7-digest-notes.md`).

```bash
# 1. Isolated stores (non-conflicting ports), real key + embedder in .env:
#    QDRANT_URL=http://localhost:6335  NEO4J_URI=bolt://localhost:7688
#    EMBEDDER=sentence-transformers    LLM_PROVIDER=anthropic  LLM_API_KEY=...
#    DATABASE_URL=sqlite:///./data/dev_corpus.db   SOURCE_MAX_AGE_DAYS=7   GITHUB_TOKEN=...
# 2. Ingest the FULL broadened registry into the PERSISTENT dev corpus (enriches only NEW events):
python -m app.cli run
# 3. Compose the weekly digest, then project it into drafts:
python -m app.cli digest --days 7
python -m app.cli posts --digest latest --vault-dir "$VAULT_DIR"
```
