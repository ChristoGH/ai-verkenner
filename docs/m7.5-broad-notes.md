## The exact recipe to run it (add the key, then one block)

Leave `za-corruption-*` and `trafficking-intel-*` **untouched**. The stores + `.env` scaffold already
exist on this branch (`docker-compose.m75.yml`); only the key is missing.

```bash
# 0. Add your key to the gitignored .env (never committed):
sed -i '' 's#^LLM_API_KEY=.*#LLM_API_KEY="sk-ant-..."#' .env
#    (optional: also set GITHUB_TOKEN="..." so the curated github_* sources fetch)
# 1. Bring up the isolated stores (non-conflicting ports; project m75broad):
docker compose -p m75broad -f docker-compose.m75.yml up -d
# 2. Ingest the FULL broadened registry into the PERSISTENT dev corpus (enriches only NEW events).
#    .env already points DATABASE_URL at data/dev_corpus.db and the stores at :6335 / :7688:
cd backend && python -m app.cli run
# 3. Compose the weekly digest, then project it into drafts (Neo4j MUST be up for convergence):
python -m app.cli digest --days 7
python -m app.cli posts --digest latest --vault-dir ~/github_repos/knowledge-vault
# 4. Tear the stores down when done (keeps data/dev_corpus.db; removes the derived-index volumes):
cd .. && docker compose -p m75broad -f docker-compose.m75.yml down -v
```
