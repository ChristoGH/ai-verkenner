## The exact recipe (corrected — see D-006)

> ⚠️ **The previous recipe here was wrong.** It said `cd backend && python -m app.cli run`. With a
> **relative** `DATABASE_URL` that resolves the corpus against `backend/`, creating a stray database
> (this is exactly what caused the D-006 incident and the stray DB deleted in D-010). The CLI must be
> run from the **repo root** with `PYTHONPATH=backend`.

Leave `za-corruption-*` and `trafficking-intel-*` **untouched** — the isolated stores use
non-conflicting ports under compose project `m75broad`.

```bash
# 0. Secrets are environment-injected by direnv from ~/.config/secrets/<repo>.env — do NOT paste
#    keys into files or chat. If LLM_API_KEY / GITHUB_TOKEN are missing, follow the runbook at
#    ~/.config/secrets/README.md. Verify names only (never values):
grep -oE '^[A-Za-z_]+=' ~/.config/secrets/ai-verkenner.env
# 1. Bring up the isolated stores (non-conflicting ports; project m75broad):
docker compose -p m75broad -f docker-compose.m75.yml up -d
# 2. Ingest the registry into the PERSISTENT dev corpus (enriches only NEW events).
#    RUN FROM REPO ROOT — the relative DATABASE_URL depends on it (D-006):
PYTHONPATH=backend python -m app.cli run
# 2b. Drain any events orphaned by an interrupted run (D-012/D-013 — this defect recurs):
PYTHONPATH=backend python -m app.cli enrich --backfill --dry-run   # then without --dry-run
PYTHONPATH=backend python -m app.cli graph-reindex
# 3. Compose the weekly digest, then project it into drafts (Neo4j MUST be up for convergence):
PYTHONPATH=backend python -m app.cli digest --days 7
PYTHONPATH=backend python -m app.cli posts --digest latest --vault-dir ~/github_repos/knowledge-vault
# 4. Tear the stores down when done (keeps data/dev_corpus.db; removes derived-index volumes):
docker compose -p m75broad -f docker-compose.m75.yml down -v
```

Record after each run: convergence entity + publishers, cost and window, and whether the generator
took the converged or the honest-degradation path. If convergence does **not** fire, that is a
correct result — the generator must make no false "converging" claim.
